# X50 Navigation 0.15.124 — CAN LIM: фаза передачи и запись CAN

- Встроена ESP 2.4: момент нажатия выбирается по фазе штатных потоков `0x283` и `0x28A`, с запасом на передачу и джиттер.
- Если подходящего окна нет, ESP ожидает его. Ожидание может занять десятки секунд; предел — до 88 секунд от начала задания. Причина ожидания, фаза и выбранный сдвиг записываются в журнал.
- Запоздавший TX останавливает задание с отдельной причиной. Пять попыток и ручная отмена сохранены, поздний статус предотвращает лишнее повторное нажатие.
- Полный CAN-поток, передачи и события записываются на microSD; имена файлов используют проверенные дату/время CAN. Светодиод показывает состояние платы и ошибки. Исправлены выделение SD-очереди и создание файлов.
- CAN остаётся в NORMAL между заданиями; чтение продолжается, отправка разрешена активному заданию.
- Сначала обновите Navigation, затем ESP кнопкой во вкладке CAN LIM. Перед прошивкой выньте microSD; верните карту при выключенном питании. Обновляйте на остановленном автомобиле.
- Проверены host-сценарии, выбор окон на записи поездки и Rooted-эмулятор. Приём команд автомобилем для ESP 2.4 ещё не подтверждён. Rootless не собирался и не проверялся.

## Сохранено из 0.15.120

- Статистика использования считается по свежему построенному маршруту Яндекс Навигатора или 2GIS, независимо от переднего плана и SCORO.
- Начало сеанса после 2 секунд наличия маршрута; завершение после 2 минут без него по последнему времени наличия маршрута. Короткие перестроения не дробят сеанс.
- CAN LIM: до 5 попыток каждого неподтверждённого нажатия — начального SET−, числовой коррекции и CANCEL. Номер попытки и причина отказа записываются в журнал.
- Позднее подтверждение автомобиля отменяет повторное нажатие. Navigation не умножает исчерпанные попытки ESP ещё на пять заданий.
- Отдельный асинхронный USB-приём и фоновая запись журнала CAN LIM.
- Ручное вмешательство, ошибки CAN/связи и общий бюджет задания сохраняют остановку без автоматического повтора.
- Защищённая сборка для Magisk + LSPosed (Rooted).
