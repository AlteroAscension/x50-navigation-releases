# X50 Navigation 0.12.20-traffic-light-timer-delay

- Добавлена настраиваемая задержка скрытия штатного таймера светофора после проезда: 0…100 м, по умолчанию 0 м.
- Расстояние считается по `getTrafficLights()` захваченного MapKit-маршрута; задерживается только скрытие штатных корневых view таймера.
- Также содержит независимые индикаторы прогресса встроенного мини-плеера из собственной `MusicSession` Навигатора.
- Protected binary Magisk module; activation required.
- Magisk module versionCode: 46.
