# X50 Navigation 0.15.100-sensor-transport

- Rotate journal files under one stable trip identity with linked archive parts; preserve the event that triggers rotation.
- Record exact revised pose deltas in compact columns with periodic checkpoints; preserve raw sensor measurements.
- Automatically capture route geometry on route activation.
- Record delivery delay from Gateway to Navigation.
- Use with Gateway 2.30.19 / ESP 1.1.21 and Simulator 1.11.23 for full multipart and compact-journal support. Older Gateway and missing-Gateway clients retain fallback.
