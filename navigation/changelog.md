# X50 Navigation 0.12.22-voice-diagnostics

- Added an opt-in, passive SpeechKit diagnostic switch in the Diagnostics tab.
- While enabled, it writes final recognised text and its caller path to the
  LSPosed log for compatibility research only.
- It does not block, modify, route or execute any Alice/Navigator command.
- Protected binary Magisk module; activation required.
