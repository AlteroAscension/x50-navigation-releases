# X50 Navigation 0.15.22-gnss-time-usb

- GNSS Share: расхождение часов телефона и ГУ больше не блокирует обучение
  и GPS-коррекции. Возраст точки и время для сравнения со скоростью автомобиля
  приводятся к часам ГУ; проверка свежести для калибровки остаётся 5 секунд.
- Повторные, переставленные и устаревшие GNSS Share точки отбрасываются;
  дополнительная задержка потока учитывается отдельно от расхождения часов.
- USB GPS: выбор устройства по имени и VID/PID, сохранение выбора и повторное
  подключение. Magisk восстанавливает доступ к выбранному приёмнику без диалога,
  если прошивка разрешает привилегированный USB API. Без системных прав
  используется штатный запрос Android.
- NMEA: GSV больше не заменяет число используемых спутников; пустой GSA
  отдельной системы не сбрасывает общий фикс. Убраны фиксы на служебных
  сообщениях, повторы одной эпохи и перенос устаревшей скорости.
- Для автоматического USB-доступа установите полный Magisk-модуль и
  перезагрузите устройство. Проверка USB на реальном приёмнике ещё требуется.
- Проверены регрессии времени и NMEA; воспроизведены временные данные двух
  полевых логов. Интерфейс и поездку с этой сборкой проверяет пользователь.
- No activation required.
