# X50 Navigation 0.15.98 — связность системы

- В HA передаётся та же исправленная инерциальная цепочка, которую получает оверлей Навигатора (до 800 точек текущего сегмента). Полный журнал сохраняет пересчёты прошлых точек.
- Начало новой сессии сбрасывает новый алгоритм и его якорь; сегменты после сброса различаются.
- При выключении Navigation снимается GPS-слушатель, запоздавшие callbacks закрытого экземпляра игнорируются.
- Для инерциальной диагностики без CAN движение берётся из свежего реального GPS: скорость приёмника или значимое смещение между точками. Вес такого расстояния ниже автомобильного. Mock GPS, плохие/старые точки и скачки отбрасываются; после получения CAN его пропадание не маскируется GPS.
- API публикации FakeGPS и IPC Rootless сохраняются. GPS fallback относится к инерциальной диагностике.

Для просмотра исправленной линии в HA обновить Integration до 0.6.6 и Simulator до 1.11.12. Control Center 0.2.1 восстанавливает пропущенные снимки после переподключения.

Проверено локально: 13 наборов Navigation, защищённая R8-сборка, упаковка Magisk. Испытание на ГУ и Rootless-устройстве ещё предстоит.

Обновление на ГУ: Magisk → Модули → X50 Navigation → Обновить, затем перезагрузить. Для Rootless доступен отдельный APK того же модуля; перепаковка Навигатора для этих изменений не требуется, хуки и IPC не менялись.

## Алгоритм из 0.15.97

Исправлены скачки при переключении свободной и маршрутной оценки: теперь они
работают в общей системе координат, меняются веса измерений. Пересчитываются
последние шесть минут пути, подробные точки сохраняются за последние 45 секунд.
Коррекция распределяется по цепочке, сохраняя форму поворотов и стык с хвостом.
Оверлей Навигатора получает всю исправленную линию, до 800 точек.

Руль и движение читаются одним снимком. При кратком устаревании данных руля их
вес плавно уменьшается; потеря связи не подменяется исправным датчиком.
Разделены конфликт датчиков, возврат GPS, подтверждённый съезд и парковка после
конца маршрута. Уточнены условия обучения компаса и рулевого коэффициента.
На прямой алгоритм сохраняет неопределённость прогресса; форму ищет в пределах
±300 м от предполагаемого участка.

Проверено: JVM-регрессии, оба предоставленных архива, защищённая R8-сборка.
На вечернем повторе с исключением половины GPS из расчёта ложных съездов нет;
медианное расхождение с исключённым GPS 4,3 м, 95-й процентиль 14,1 м.
Это результаты повторного расчёта, на ГУ эта версия ещё не проверена.

Алгоритм работает непосредственно в Android-модуле при включённой миникарте
или инерциальной диагностике. Его оценка поправки прогресса пока диагностическая.

Обновление: Magisk → Модули → X50 Navigation → Обновить. После установки
перезагрузить ГУ. Для проверки включить миникарту и запись журнала поездок.
